Make your own and share it.

Make a widget in WinDotra → Store → Make a widget, or a style in Styles → Make your own. Then export it and send a pull request:

  1. Fork the repository.
  2. Put your file in docs/store/widgets or docs/store/styles.
  3. Add a line for it to docs/store/index.json and open a pull request with a screenshot.

A widget is just this:

{
 "Format": "windotra-widget", "Version": 1,
 "Name": "Greeting", "Author": "you", "Description": "A friendly hello.",
 "Width": 1, "Background": "", "Accent": "", "Link": "",
 "Lines": [
  { "Text": "{greeting}", "Size": 15, "Weight": "SemiBold", "Color": "", "Align": "Left" },
  { "Text": "{time}", "Size": 40, "Weight": "Light", "Color": "", "Align": "Left" }
 ]
}

Live values: {time} {time:h:mm tt} {date} {date:dddd} {day} {greeting} {cpu} {ram} {battery} {song} {artist} {days-until:2026-12-24} {countdown:2026-12-31 23:59}.
